# Plasma Launcher

Projeto experimental de launcher nativo para KDE Plasma 6, utilizando QML e Qt Quick.

## Status

Planejamento. Nenhum pacote foi instalado e nenhum Plasmoid funcional foi implementado.

## Diretrizes

- Menu com categorias do KDE e apresentação visual inspirada no Andromeda.
- KRunner permanece responsável pela pesquisa global.
- C++ e Electron não fazem parte da stack.
- Priorizar APIs estáveis e integração nativa com Plasma 6.
